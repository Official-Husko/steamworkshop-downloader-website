1Admin — auth, console, key handling, logs, service controls

Same phosphor system as the public site, with two deliberate differences so you never confuse the two: the header reads WORKSHOP.DL / ADMIN against an inverted bar, and every destructive control is amber or red rather than green. No public footer disclaimer here. Left rail is the same on every admin page. Anything that reveals a visitor IP or a full key is masked until you click to reveal, and the reveal is itself logged in the audit trail.

REDEMPTION FLOW
Reveal shows the key once, in clear, for 30 seconds. Redeem marks it used and asks which app id it unlocked, which is what flips the game to covered on the public list and closes its request queue entry.
VOID
Discards the key without redeeming and deletes it from storage. Used for duplicates and anything that looks resold. Irreversible, and the donor is not told automatically.
